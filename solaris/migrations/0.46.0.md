## Summary

Framework 0.46.0 lets a top-level OpenCode 2 session compact itself once its context passes a set size (default
500k tokens), at a moment it picks, after saving a checkpoint, instead of waiting for OpenCode's automatic
compaction near the window's limit. Below, `<pack>/` is the project's ai-pack folder and `<project>` its path from
the Solaris root.

- **New framework skill** `opencode2-selfcompact` and tool `uv run -m solaris.tools.session_compact`
  (`check`, `request [--now|--force|--dry-run]`, `set-limit`). In project work the checkpoint is the project's
  `<pack>/.memory/context.md`, which `request` wants rewritten in the last 20 minutes.
- **The due line:** in an OpenCode 2 session, `interactions add` prints one more line when a compaction is due
  (`self-compaction: ... DUE: ...`); elsewhere its output is unchanged.
- **Settings** (all optional): `selfcompact.enabled`, `selfcompact.limit`, `selfcompact.min_interval_minutes` in
  `<pack>/.memory/config.json` or `<pack>/defaults.json`, over the framework's `.memory/config.json`.
- **Pack:** the harness notes (`<pack>/info/harnesses.md`, rev 8) describe OpenCode 2's compaction route.

## Moved Paths

None. New files outside packs: `.memory/selfcompact/<session id>.md` in the framework (checkpoints of orchestrator
and ad-hoc task sessions) and `~/.cache/solaris/selfcompact/<session id>.json` (per-session limits).
