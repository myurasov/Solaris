## Summary

Framework 0.38.0 adds the bundled **`resource-sharing` plugin**: claim files kept on each host
(`~/.solaris/claims/`) let several agents and projects share machines without stepping on each other -
jobs launch pinned to what they claimed, lower-priority jobs yield, every host has exactly one owning
project with guest requests, and an owner audit keeps paid instances from being abandoned. The bundled
**`kaggle` plugin** moves to 0.3.0: a generic competition playbook (`how-to-kaggle`), a saved leaderboard
history, one Kaggle account shared between projects, and a competition-forum watch; its gateway moved to
`shared/tools/kaggle.py` and its gateway skill is renamed `kaggle-cli` (the plugin's own
`migrations/0.2.0.md` moves copied installs). No ai-pack schema change: a project that attaches neither
plugin needs no file edit (marker migration).

## Pre-flight Checks

- [ ] `ai/manifest.json` exists and is valid JSON.

## Migrate

1. If the project has `kaggle` attached in copy mode, update the plugin overlay through `update-project`,
   which applies `plugins/kaggle/migrations/0.2.0.md` (gateway path and skill rename) and fast-forwards
   the rest. Link-mode installs follow the plugin source and need nothing.
2. Optionally attach the new plugin: `install-plugin` ("add plugin resource-sharing to `<project>`", or
   "link plugin resource-sharing to `<project>`" while developing it). Attaching only copies the overlay
   and surfaces the setup notes (the project's hosts in `ai/.memory/hosts.json`, an optional
   `ai/.memory/resource-sharing.json` to share hosts with other projects); nothing is installed on a host
   until the owning project runs `hostclaims.py install --host <name>`.
3. `uv run -m solaris.tools.version set --dir projects/<slug> 0.38.0`.

## Validate

- [ ] `uv run -m solaris.tools.version check --dir projects/<slug>` exits 0.
- [ ] If `kaggle` is attached in copy mode: `ai/plugins/kaggle/tools/kaggle.py` and
      `ai/plugins/kaggle/kaggle-cli.skill.md` exist, and the old `ai/plugins/kaggle/kaggle.py` and
      `ai/plugins/kaggle/kaggle.skill.md` are gone.
- [ ] If `resource-sharing` was attached: `python3 ai/plugins/resource-sharing/tools/hostclaims.py --help`
      (copy mode) or `python3 <solaris>/plugins/resource-sharing/shared/tools/hostclaims.py --help`
      (link mode) prints the command list and exits 0.

## Revert

1. If `resource-sharing` was attached during this migration: from its owning project, run
   `hostclaims.py uninstall --host <name>` for each host it installed on, then detach it (remove
   `ai/plugins/resource-sharing/` or the `ai/plugins/resource-sharing.link.md` pointer and the manifest
   `plugins[]` entry), then `uv run -m solaris.tools.revs ff --dir projects/<slug>` (re-renders the
   `ai/README.md` plugin list) and `uv run -m solaris.tools.revs baseline --dir projects/<slug>`.
2. A copied `kaggle` overlay reverts through the plugin's own `migrations/0.2.0.md` Revert section.
3. `uv run -m solaris.tools.version set --dir projects/<slug> 0.37.0`.
