## Summary

Framework 0.34.0 makes the primary persona's name a pack setting and gives additional personas a
first-class home. The ai-pack template now renders the primary persona's file names
(`ai/<primary>.agent.md`, `ai/<primary>.instructions.md`) from `ai/manifest.json` -> `agents.primary`
(absent = `engineer`, so every existing pack renders exactly as before); **role briefs** live at
`ai/agents/<role>.agent.md` (frontmatter `description` / `tier` / `access` above the brief; project
content, no rev marker) and are listed in the re-rendered pack README; a role is used by telling a model
to act as that file. The new `solaris.tools.agents` tool validates briefs and performs the rename. No
file edit is required for a pack that keeps `engineer` and defines no roles (marker migration); the
optional steps below opt a project in.

## Pre-flight Checks

- [ ] `ai/manifest.json` exists and is valid JSON.
- [ ] The primary persona file is present: `ai/engineer.agent.md` (or `ai/<agents.primary>.agent.md`).

## Migrate

1. `uv run -m solaris.tools.revs ff --dir projects/<slug>` re-renders `AGENTS.md`, the persona file,
   and `ai/README.md` (which now carries the persona list) from the 0.34.0 templates; then
   `uv run -m solaris.tools.revs baseline --dir projects/<slug>`.
2. Optional - rename the primary persona:
   `uv run -m solaris.tools.agents --dir projects/<slug> --rename-primary <role>` moves
   `ai/engineer.agent.md` + `ai/engineer.instructions.md` to `ai/<role>.*`, sets `agents.primary`, and
   re-renders the managed files. Fix any remaining references it lists (a grep line is printed).
3. Optional - add role briefs: copy `solaris/templates/agents/role.agent.md` to
   `ai/agents/<role>.agent.md`, fill it in, validate with
   `uv run -m solaris.tools.agents --dir projects/<slug> --check`, then re-run `revs ff` so the pack
   README lists them.
4. `uv run -m solaris.tools.version set --dir projects/<slug> 0.34.0`.

## Validate

- [ ] `uv run -m solaris.tools.revs classify --dir projects/<slug>` runs clean.
- [ ] `uv run -m solaris.tools.agents --dir projects/<slug> --check` exits 0.
- [ ] `uv run -m solaris.tools.version check --dir projects/<slug>` exits 0.

## Revert

1. If step 2 renamed the primary: `uv run -m solaris.tools.agents --dir projects/<slug> --rename-primary engineer`.
2. If step 3 added briefs: delete `ai/agents/`, then `uv run -m solaris.tools.revs ff --dir projects/<slug>`.
3. `uv run -m solaris.tools.version set --dir projects/<slug> 0.33.0`.
