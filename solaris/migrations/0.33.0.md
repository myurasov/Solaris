## Summary

Framework 0.33.0 adds the bundled **`kaggle` plugin** - Kaggle for agents through the official
Kaggle CLI, CLI only: a stdlib gateway (`kaggle.py`) that pins the CLI and installs it separately
into each project or ad-hoc task that uses it, a gateway skill that routes agents to it and to
Kaggle's own agent skill (vendored unmodified at the same version), and an always-on rule that
confirms every write to Kaggle first. It also formalizes **vendored upstream trees** in plugins
(third-party files kept identical to upstream, marked by an `UPSTREAM.md`, like `nvidia-brev`'s
`brev-cli/` mirror): `solaris.tools.toc` now leaves them untouched and `import-plugin` never folds
project edits in them back. No ai-pack schema change, so this is a marker migration: plugin
content updates (the `reporting` font and TOC defaults, the `apple-asc` and `gmail` skill lessons)
arrive through the usual revision sync. Attaching `kaggle` is opt-in via `install-plugin`.

## Pre-flight Checks

- [ ] `ai/manifest.json` exists and is valid JSON.

## Migrate

1. Optionally attach the new plugin: `install-plugin` ("add plugin kaggle to `<project>`", or
   "link plugin kaggle to `<project>`" while developing it). The first Kaggle call through its
   gateway installs the pinned CLI from PyPI into the project (`.venv-kaggle/`, git-ignored);
   signing in once per machine is the skill's Signing In step.
2. `uv run -m solaris.tools.version set --dir projects/<slug> 0.33.0`.

## Validate

- [ ] `uv run -m solaris.tools.version check --dir projects/<slug>` exits 0.
- [ ] If `kaggle` was attached: from the project root, `python3 ai/plugins/kaggle/kaggle.py --version`
      (copy mode) or `python3 <solaris>/plugins/kaggle/shared/kaggle.py --version` (link mode)
      prints `Kaggle CLI 2.2.4`. No sign-in needed; the first call installs the pinned CLI.

## Revert

1. If `kaggle` was attached during this migration: detach it (remove `ai/plugins/kaggle/` or the
   `ai/plugins/kaggle.link.md` pointer - in an embedded project also its line in the repo
   `.gitignore` - the manifest `plugins[]` entry, and the project's `.venv-kaggle/`), then
   `uv run -m solaris.tools.revs ff --dir projects/<slug>` (re-renders the `ai/README.md` plugin
   list) and `uv run -m solaris.tools.revs baseline --dir projects/<slug>`.
2. `uv run -m solaris.tools.version set --dir projects/<slug> 0.32.0`.
