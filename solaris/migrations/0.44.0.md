## Summary

Framework 0.44.0 adds plugin dependencies and project types that plugins provide, and moves general agent-team
practice from the Kaggle playbook into the pack templates every project receives. Below, `<pack>/` is the project's
ai-pack folder.

- **Plugin dependencies:** a plugin manifest may declare `dependencies` (`required`, `optional`). `install-plugin`
  attaches the required ones first (transitively) and offers the optional ones once; `uv run -m
  solaris.tools.plugins check --dir projects/<slug>` must pass after every update.
- **Project types from plugins:** `plugins/<plugin>/<type>.project.md` with an overlay in `project-types/<type>/`;
  `create-project` asks its questions, applies its overlay, attaches its plugins and runs its Setup Steps. The kaggle
  plugin (0.9.0) ships `kaggle:competition`.
- **Agent-team practice in every pack:** the primary persona (rev 50: paused versus dead queues, todos kept live,
  autonomy proven in the real harness, compaction budgets, no automated collection of personal data, safety checks
  reported rather than worked around, owner-approved command lists), the subagents rule (rev 9: short coordinator
  turns, checking the model and effort a worker ran, errors that never acknowledge work, worker deletions only as
  the delegator pre-approves or approves, a private scratch folder per worker), the token-economy rule (rev 6: script
  the watching; wake an agent only to decide), the handover skill (rev 6: the take-over check against the remote
  branch; the newest handover note is the pause marker) and the harness notes (rev 6: OpenCode). No file fixes an
  effort level: the role templates drop `effort`, and the rules pass the effort the owner chose.
- **Kaggle playbook:** its Agent Organization section points to these files; the core is 58 KB.

## Migrate

1. `uv run -m solaris.tools.revs ff --dir projects/<slug>` (persona rev 50, subagents rule rev 9, token-economy rule
   rev 6, handover rev 6, harness notes rev 6, and the copy-mode plugin overlays: kaggle 0.9.0).
2. `uv run -m solaris.tools.plugins check --dir projects/<slug>`: attach any required dependency it names
   (`install-plugin`), and tell the owner about the optional ones it suggests.
3. Record the plugin versions in `<pack>/manifest.json` `plugins[]`, then
   `uv run -m solaris.tools.version set --dir projects/<slug> 0.44.0`, `revs ff` and `revs baseline` again.
4. The project's own session, after the update: re-read the pack. A pack whose own lines say the main session runs
   every deletion follows the subagents rule now (workers delete what the master pre-approved or approves; keep any
   registry tag on its line). Role briefs (`<pack>/*.agent.md` other than the primary) may drop a fixed `effort`.
