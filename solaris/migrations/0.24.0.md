## Summary

Framework 0.24.0 teaches both refresh flows to handle a force-pushed upstream history rewrite (adopt it
instead of merging old and new histories together) and codifies the structured full-diff release-notes
style. For an existing project this is a content-only template sync: `ai/refresh.skill.md` rev 6 and
`ai/engineer.agent.md` rev 31 (Release Notes bullet in the Commit Policy). No ai-pack schema change.

## Pre-flight Checks

- [ ] `ai/manifest.json` exists and is valid JSON.
- [ ] `uv run -m solaris.tools.revs classify --dir <project>` runs clean (no unresolved conflicts).

## Migrate

1. Sync the templates: `uv run -m solaris.tools.revs ff --dir <project>` (brings `ai/refresh.skill.md`
   rev 6 and `ai/engineer.agent.md` rev 31). Resolve any `merge-up`/`conflict` per `update-project`.
2. Re-record the baseline: `uv run -m solaris.tools.revs baseline --dir <project>`.
3. `uv run -m solaris.tools.version set --dir <project> 0.24.0`.

## Validate

- [ ] `ai/refresh.skill.md` shows `_Rev. 6_` and mentions rewritten upstream history in its Pull step.
