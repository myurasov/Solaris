## Summary

Projects gain first-class **workspaces**: one or more self-contained top-level work tracks per project
(own `setup.md`/`spec.md`/deps, no file references into siblings; shared inputs live outside; `source/` is
the default and a flat project has just that one; the single ai-pack is shared across all). Committed ai
files also gain **git-collaboration conventions** (diff-friendly wrapping, mechanical
`manifest.json` `revisions` conflict resolution, `*.jsonl merge=union`). Both are additive: a flat project
needs nothing beyond the revisions sync; a project already using workspace-shaped folders registers them.

## Pre-flight checks

- [ ] `ai/manifest.json` exists and is valid JSON.
- [ ] `uv run -m solaris.tools.revs classify --dir projects/<slug>` shows no unresolved `conflict` rows.

## Migrate

1. Sync materialized files by revision (brings `AGENTS.md` / `ai/engineer.agent.md` - now carrying the
   Workspaces + Authoring sections - forward): `uv run -m solaris.tools.revs ff --dir projects/<slug>`.
2. **Multi-track projects only:** register the existing workspace folders - add
   `"workspaces": ["<dir>", ...]` under `project` in `ai/manifest.json`, and a workspace table (see the
   template `engineer.instructions.md`) to `ai/engineer.instructions.md`. Ensure each workspace has a
   `setup.md`; stubs live at `solaris/templates/workspace/`.
3. **Repos with committed `*.jsonl` logs (embedded packs):** add `*.jsonl merge=union` to the repo's
   `.gitattributes`.
4. Record the version: `uv run -m solaris.tools.version set --dir projects/<slug> 0.20.0`.

## Validate

- [ ] `uv run -m solaris.tools.version check --dir projects/<slug>` exits 0.
- [ ] `uv run -m solaris.tools.revs classify --dir projects/<slug>` reports in-sync.
- [ ] Multi-track projects: every entry in `project.workspaces` exists as a top-level folder with a
      `setup.md`.

## Revert

Set `framework_version` back to `0.19.0` in `ai/manifest.json`; optionally remove `project.workspaces`,
the workspace table, and the `.gitattributes` line (all additive).
