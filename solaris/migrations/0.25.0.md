## Summary

Framework 0.25.0 restructures the ai-pack: always-on pack rules live in `ai/rules/` (new: leveled
subagent delegation and switchable YAGNI mode), trigger-invoked skills live in `ai/skills/` (the
init/refresh stubs move there from flat `ai/`), perishable reference data the rules point at
(model tiers, harness capabilities) lives in `ai/info/`, and behavior switches read the committed
`ai/defaults.json` overridden per key by the private `ai/.memory/config.json`. Pack rules, skills,
and info files are now revision-tracked, so `revs ff`/`classify` cover them from here on.
Templates: `ai/engineer.agent.md` rev 33, pack `AGENTS.md` rev 15 (the `ai/info/` files and these
rev levels land in patch 0.25.1 - the same `revs ff` run brings them when updating to 0.25.1+).

## Pre-flight Checks

- [ ] `ai/manifest.json` exists and is valid JSON.
- [ ] `uv run -m solaris.tools.revs classify --dir <project>` runs (verdicts for `ai/rules/*` and
      `ai/skills/*` will show `missing` - expected before the move).

## Migrate

1. Move the skill stubs (preserves any project customization): `mkdir -p <project>/ai/skills` then
   `git mv` (embedded mode) or `mv` `ai/init.skill.md` and `ai/refresh.skill.md` into `ai/skills/`.
2. Sync tracked files: `uv run -m solaris.tools.revs ff --dir <project>` - brings
   `ai/rules/subagents.rule.md` (rev 2) + `ai/rules/yagni.rule.md` (rev 1) +
   `ai/info/model-tiers.md` + `ai/info/harnesses.md` (rev 1) and fast-forwards
   `ai/engineer.agent.md` to rev 33 and `AGENTS.md` to rev 15. Resolve any `merge-up`/`conflict`
   per `update-project` (a customized init/refresh stub classifies against the template - keep the
   project side via merge-up).
3. Seed the defaults: copy `solaris/templates/ai-pack/ai/defaults.json` to `<project>/ai/defaults.json`
   (skip if the project already has one).
4. Re-record the baseline: `uv run -m solaris.tools.revs baseline --dir <project>`.
5. `uv run -m solaris.tools.version set --dir <project> 0.25.0`.

## Validate

- [ ] `ai/rules/` holds `subagents.rule.md` + `yagni.rule.md`; `ai/info/` holds `model-tiers.md` +
      `harnesses.md`; `ai/skills/` holds the init/refresh stubs; no `*.skill.md` remains flat in

- [ ] `ai/defaults.json` parses and carries `"subagents.level"` + `"yagni.enabled"`.
- [ ] `uv run -m solaris.tools.revs classify --dir <project>` reports every tracked file `in-sync`

- [ ] `uv run -m solaris.tools.version check --dir <project>` exits 0.

## Revert

1. Move `ai/skills/init.skill.md` and `ai/skills/refresh.skill.md` back to flat `ai/`; remove
   `ai/rules/`, `ai/skills/`, `ai/info/`, and `ai/defaults.json`.
2. Restore the previous `ai/engineer.agent.md` and `AGENTS.md` from git (or the prior baseline) and
   re-run `revs baseline --dir <project>`.
3. `uv run -m solaris.tools.version set --dir <project> 0.24.0`.
