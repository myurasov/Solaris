## Summary

Framework-level change with an optional per-project step. A new bundled plugin
**`plugins/browserctl/`** makes browser automation CLI-based: `browserctl.py` launches
Playwright's Chromium directly on stable per-profile CDP ports (per-project namespaces, clean
first-use profiles, ephemeral profiles on demand), replacing the Playwright MCP server, which is
removed from `mcp.json.example`. Existing projects keep working - their gitignored runtime MCP
configs are not touched by this migration.

## Pre-flight checks

- [ ] `ai/manifest.json` exists and is valid JSON.

## Migrate

1. Nothing mandatory - this is a marker migration for the version step.
2. **Optional, recommended for projects that automate a browser:** attach the plugin
   ("add plugin browserctl to `<slug>`"), then delete the `playwright` entry from the project's
   `.mcp.json` + `.cursor/mcp.json` (and re-check `uv run -m solaris.tools.mcp_sync --dir
   projects/<slug> --check`). At the framework root, users can likewise delete the `playwright`
   entry from their live `.mcp.json` / `.cursor/mcp.json` copies.

## Validate

## Revert

1. Restore the `playwright` entries in the runtime MCP configs (copy from any pre-0.21.0
   `mcp.json.example` in git history) and detach the browserctl plugin if it was attached.
