## Summary

Framework 0.47.0 lets a project's primary session run unattended under OpenCode 2 as an agent of autocode (the
owner's agent server: wakes, messages, locks, jobs, approvals, compaction), lets one session turn Solaris
self-compaction off for itself, and lets housekeeping follow data folders kept on another drive. Below, `<pack>/`
is the project's ai-pack folder and `<project>` its path from the Solaris root.

- **New bundled plugin** `autocode` 0.1.0, opt-in per project: `autocode.rule.md` (always-on, dormant outside a
  session whose shells carry `AUTOCODE_SESSION`) replaces what the persona ties to harness hooks and the session
  clock; `tools/wakes.py` prints wake specs from `<pack>/.memory/schedule.json`.
- **Persona rev 52** (Long-Running Work): in an autocode session the plugin's rule replaces the clock, the Stop hook,
  the session-start reload and self-compaction. Nothing changes for other sessions.
- **`session_compact set-limit off`** turns self-compaction off for the calling session only (`--clear` drops it).
- **housekeeping:** `linked_roots` in `<pack>/housekeeping.json` (for example `["__data", "__out"]`) makes a listed
  top-level symlink to a folder outside the project count as part of the project; a listed link whose target is
  missing is an error, so an unmounted drive never reads as an empty folder.
- **docker-home** 0.1.2 installs OpenCode 2 in its containers on a per-project service port.

## Moved Paths

None. New files outside packs: `~/.cache/solaris/selfcompact/<session id>.json` may now hold `{"enabled": false}`
(written by `set-limit off`) in place of a limit.

## Migrate

1. `uv run -m solaris.tools.revs ff --dir <project>` (persona rev 52).
2. `uv run -m solaris.tools.version set --dir <project> 0.47.0`, then `revs ff` and `revs baseline` again.
3. Optional: a project whose `__data/` or `__out/` is a symlink to another drive adds `"linked_roots": ["__data",
   "__out"]` to `<pack>/housekeeping.json`.
4. Optional: a project whose primary session should run under autocode attaches the `autocode` plugin
   (`install-plugin`) and starts the session as its README says.

plugin if attached, and remove any `linked_roots` key; nothing older reads it.
