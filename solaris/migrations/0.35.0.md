## Summary

Framework 0.35.0 adds the bundled **`docker-home` plugin**: a per-project Linux container that runs the
coding harness (claude, codex, opencode) with only the project folder bind-mounted, so nothing above
the project (framework files, other projects, host dotfiles) exists for the agent. Seven `dh-*.sh`
shortcut scripts in the overlay manage it from any terminal (`build`, `start`, `stop`, `enter`,
`status`, `rebuild`, `remove`); the skill drives the same scripts strictly on the user's request, and
the always-on rule carries the boundary contract. No ai-pack schema change: a project that does not
attach the plugin needs no file edit (marker migration). Attaching is opt-in via `install-plugin`, and
nothing is built or started at attach time.

## Pre-flight Checks

- [ ] `ai/manifest.json` exists and is valid JSON.

## Migrate

1. Optionally attach the new plugin: `install-plugin` ("add plugin docker-home to `<project>`", or
   "link plugin docker-home to `<project>`" while developing it). Attaching only copies the overlay
   and surfaces the setup notes (Docker on the machine where sessions run; NVIDIA container toolkit
   for GPU pass-through; Linux inside). Build the container later with "build docker home" when the
   project needs one.
2. `uv run -m solaris.tools.version set --dir projects/<slug> 0.35.0`.

## Validate

- [ ] `uv run -m solaris.tools.version check --dir projects/<slug>` exits 0.
- [ ] If `docker-home` was attached: from the project root, `bash ai/plugins/docker-home/dh-status.sh`
      (copy mode) or `bash <solaris>/plugins/docker-home/shared/dh-status.sh` (link mode) prints the
      project, slug and state lines and exits 0 (Docker need not be running for this).

## Revert

1. If `docker-home` was attached during this migration: remove any container it built
   (`bash ai/plugins/docker-home/dh-remove.sh`, which asks before deleting the state dir under
   `~/.solaris/docker-home/<slug>/`), then detach it (remove `ai/plugins/docker-home/` or the
   `ai/plugins/docker-home.link.md` pointer and the manifest `plugins[]` entry), then
   `uv run -m solaris.tools.revs ff --dir projects/<slug>` (re-renders the `ai/README.md` plugin list)
   and `uv run -m solaris.tools.revs baseline --dir projects/<slug>`.
2. `uv run -m solaris.tools.version set --dir projects/<slug> 0.34.0`.
