## Summary

Framework 0.26.0 adds the bundled **`report` plugin** (findings-report authoring + zero-npm-dep
PDF rendering via installed Chrome; per-project theme: fonts, accent color, page furniture) and
extends `solaris.tools.revs` with rev markers for `.js`/`.sh`/`.css` (shebang-aware) plus
recursive tracking of every marker-capable file under a plugin's `shared/` (previously flat
`shared/*.md` only). No ai-pack schema change; this is a **marker migration** - existing projects
need no file edits. Attaching the plugin is opt-in via `install-plugin`.

## Pre-flight Checks

- [ ] `ai/manifest.json` exists and is valid JSON.

## Migrate

1. Nothing mandatory. Optionally attach the new plugin: `install-plugin` ("add plugin report to
   `<project>`") - it materializes `ai/report/` and seeds `reports/theme.css` +
   `reports/report.json` (theme defaults: Helvetica Neue + Solaris purple; NVIDIA projects
   typically override to NVIDIA Sans + NVIDIA green #76b900).
2. Projects with plugins already attached: `uv run -m solaris.tools.revs baseline --dir
   projects/<slug>` once, so nested plugin asset files (now tracked) enter the manifest baseline.
3. `uv run -m solaris.tools.version set --dir projects/<slug> 0.26.0`.

## Validate

- [ ] `uv run -m solaris.tools.revs classify --dir projects/<slug>` runs clean (and, where the
      report plugin is attached, lists `ai/report/report.skill.md` + `ai/report/assets/*`).
- [ ] `uv run -m solaris.tools.version check --dir projects/<slug>` exits 0.

## Revert

1. If the plugin was attached during this migration: remove `ai/report/`, the manifest
   `plugins[]` entry `{"name": "report", ...}`, and re-run
   `uv run -m solaris.tools.revs baseline --dir projects/<slug>`.
2. `uv run -m solaris.tools.version set --dir projects/<slug> 0.25.2`.
