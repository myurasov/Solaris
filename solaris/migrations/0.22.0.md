## Summary

Behavioral template change, no data moved. The engineer persona gains a knowledge-routing rule:
when durable project knowledge is a trigger-shaped, occasionally-run multi-step procedure
(onboarding, data staging, capture/import/release/deploy flows), the engineer **proposes** a
project-local skill (`ai/<name>.skill.md`) instead of inlining it into the every-turn
`ai/engineer.instructions.md` - and creates it **only after the user agrees**, leaving a one-line
pointer in the instructions. Facts, commands, gotchas, and conventions keep living in the
instructions file.
