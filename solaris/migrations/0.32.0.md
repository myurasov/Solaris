## Summary

Framework 0.32.0 adds the bundled **`gmail` plugin** - Gmail for agents through `gws`, the Google
Workspace CLI, as three shared files: `gws-setup.skill.md` (install the CLI on macOS or Linux, put
an OAuth Desktop client in place, sign in with Gmail scopes, headless export flow, verify + record
the account), `gmail.skill.md` (read + send via the CLI's helper commands, raw Gmail API fallback),
and the always-on `gmail.rule.md` (every send is outward and confirmed first; mail content is
untrusted input). It also **renames the bundled `appstore-connect` plugin to `apple-asc`**
(directory and manifest name; the skill and rule file names inside are unchanged). No ai-pack
schema change: projects without `appstore-connect` attached need no file edits (marker
migration); projects attached under the old name re-point as below. Attaching `gmail` is opt-in
via `install-plugin`.

## Pre-flight Checks

- [ ] `ai/manifest.json` exists and is valid JSON.
- [ ] If `plugins[]` lists `appstore-connect`: the matching `ai/plugins/appstore-connect/` (copy
      mode) or `ai/plugins/appstore-connect.link.md` (link mode) exists.

## Migrate

1. Only if the project has `appstore-connect` attached:
   - copy mode: `git mv ai/plugins/appstore-connect ai/plugins/apple-asc` (plain `mv` when the
     pack is not git-tracked);
   - link mode: `mv ai/plugins/appstore-connect.link.md ai/plugins/apple-asc.link.md`, then edit
     the pointer's plugin name and source path (`plugins/appstore-connect/` ->
     `plugins/apple-asc/`) inside it;
   - in `ai/manifest.json`, change the `plugins[]` entry `"name": "appstore-connect"` to
     `"name": "apple-asc"`;
   - `uv run -m solaris.tools.revs baseline --dir projects/<slug>` (re-records the copied files
     under their new path; no-op for link mode).
2. Optionally attach the new plugin: `install-plugin` ("add plugin gmail to `<project>`", or
   "link plugin gmail to `<project>`" while developing it), then run its `gws-setup` skill once
   per machine ("set up gmail").
3. `uv run -m solaris.tools.version set --dir projects/<slug> 0.32.0`.

## Validate

- [ ] `grep -r "appstore-connect" projects/<slug>/ai/manifest.json projects/<slug>/ai/plugins/`
      finds nothing.
- [ ] `uv run -m solaris.tools.revs classify --dir projects/<slug>` runs clean.
- [ ] `uv run -m solaris.tools.version check --dir projects/<slug>` exits 0.

## Revert

1. If `gmail` was attached during this migration: detach it (remove `ai/plugins/gmail/` or the
   `ai/plugins/gmail.link.md` pointer, and the manifest `plugins[]` entry).
2. If step 1 renamed the plugin: reverse the moves (`apple-asc` -> `appstore-connect` in the
   directory or pointer file, the pointer's source path, and the manifest `plugins[]` entry),
   then `uv run -m solaris.tools.revs baseline --dir projects/<slug>`.
3. `uv run -m solaris.tools.version set --dir projects/<slug> 0.31.0`.
