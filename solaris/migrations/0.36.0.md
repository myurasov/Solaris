## Summary

Framework 0.36.0 makes every **role persona** the same two-file pair as the primary persona: the brief
`ai/agents/<role>.agent.md` (unchanged) plus `ai/agents/<role>.instructions.md`, the role's persistent,
committable know-how (procedures, gotchas, lessons) that the role reads on start and rewrites in place
when it learns something durable - a role running without write access hands the update back in its
report for the primary persona to apply. Short-term and machine-local state stays in the pack's shared
`ai/.memory/`; roles have no memory store of their own. `solaris.tools.agents --check` reports a brief
without its instructions file as incomplete, and the pack README's Personas list links both files. Packs
without role personas need no file edit beyond the re-render (marker-like).

- [ ] `ai/manifest.json` exists and is valid JSON.

## Migrate

1. `uv run -m solaris.tools.revs ff --dir projects/<slug>` then
   `uv run -m solaris.tools.revs baseline --dir projects/<slug>` - re-renders `AGENTS.md`, the primary
   persona, and `ai/README.md` with the pair wording. `ai/<primary>.instructions.md` is seeded once and
   never re-rendered: by hand, extend its "do not live here" sentence with "and know-how that belongs to
   one role persona (`ai/agents/<role>.instructions.md`, kept by that role)" (template rev 11 wording) -
   skip when the pack has no role personas and you do not plan any.
2. For each existing `ai/agents/<role>.agent.md`: copy `solaris/templates/agents/role.instructions.md`
   to `ai/agents/<role>.instructions.md`, replace the `<Role>` / `<role>` / `<Project>` placeholders,
   and seed it with what that role already knows (from the brief, the primary's instructions, or the
   session context). Add a "Works from" pointer to the file in the brief if the brief lists its inputs.
3. `uv run -m solaris.tools.agents --check --dir projects/<slug>` exits 0, then re-run `revs ff` +
   `revs baseline` so the README's Personas list links the new files.
4. `uv run -m solaris.tools.version set --dir projects/<slug> 0.36.0`.

## Revert

Presumes the framework checkout is back on 0.35.0 (under 0.36.0 tooling, `agents --check` reports a brief
without its instructions file as incomplete).

1. Delete the `ai/agents/<role>.instructions.md` files added in step 2 (their content is the only loss)
   and remove the "Works from" / "Returns" pointers to them that step 2 added to each brief; drop the
   sentence added by hand to `ai/<primary>.instructions.md` in step 1.
2. `uv run -m solaris.tools.version set --dir projects/<slug> 0.35.0`, then `revs ff` + `revs baseline`.
