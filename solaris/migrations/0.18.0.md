## Summary

The ai-pack's private memory directory moves from `ai/memory/` to `ai/.memory/` (dot-prefixed,
matching its private/hidden nature). All framework docs, templates, skills, and bundled plugins
now reference `ai/.memory/`. Breaking for any tooling or doc that hardcodes the old path; file
contents are untouched (a pure rename). v0.18.0 also adds the `nvidia-brev` plugin (autonomous
Brev cloud-GPU run lifecycle) - no migration needed for that.

## Pre-flight checks

- [ ] `ai/manifest.json` exists and is valid JSON.
- [ ] `ai/memory/` exists (if `ai/.memory/` already exists, the pack is already migrated - stop).

## Migrate

1. Rename the directory: `mv ai/memory ai/.memory` (it is gitignored - plain `mv`, no `git mv`).
2. In the project's `.gitignore`, replace the `ai/memory/` pattern with `ai/.memory/`.
3. Sweep text references in the ai-pack and project docs: replace `ai/memory` with `ai/.memory`
   in `AGENTS.md`, `ai/*.md`, `ai/manifest.json` (comments), `ai/<plugin>/*.md` overlays,
   `README.md`, and any workspace `setup.md`/spec files that mention the private layer.
4. If any project code reads `ai/memory/...` paths directly, point it at `ai/.memory/`
   (bundled plugin code - e.g. visual-qa's `eyes.py` - already falls back to the old path).

## Validate

- [ ] `ai/.memory/` exists with the same files as before (`resources.md`, `interactions.jsonl`, ...).
- [ ] `ai/memory/` no longer exists.
- [ ] `grep -rn "ai/memory" <project>` returns no hits outside historical logs/archives.
- [ ] `.gitignore` covers `ai/.memory/`; `git status` shows no newly tracked private files.

## Revert

1. `mv ai/.memory ai/memory`.
2. Reverse the `.gitignore` and text-reference edits.
