## Summary

The plugin is renamed from `report` to `reporting`, and (with Solaris 0.28.0) plugin overlays now
materialize under `ai/plugins/<name>/` instead of `ai/<name>/`. The materialized copy therefore moves
from `ai/report/` to `ai/plugins/reporting/`, and every report HTML source must link the stylesheet at
its new path. Rendered PDFs are unaffected.

## Pre-flight checks

- [ ] `ai/manifest.json` lists `report` in `plugins[]`.
- [ ] `ai/report/` exists (copy install; a linked install just re-points its link file instead).

## Migrate

1. Move the materialized copy: `git mv ai/report ai/plugins/reporting` (create `ai/plugins/` first if
   this is the project's first plugin there; a pack already migrated to Solaris 0.28.0 moves from
   `ai/plugins/report/` instead).
2. Copy `plugins/reporting/shared/*` over the moved copies (picks up the renamed paths inside
   `report.skill.md` rev 4 and `assets/style.css` rev 2).
3. In `ai/manifest.json` `plugins[]`, change the entry to `{"name": "reporting", "version": "0.2.0"}`.
4. In every `reports/html/*.html`, update the stylesheet link:
   `../../ai/report/assets/style.css` -> `../../ai/plugins/reporting/assets/style.css`.
5. Fix any other project-owned references to `ai/report/` (grep the project; typical spots:
   `reports/theme.css` header comment, `ai/engineer.instructions.md`, workspace setup docs).
6. Rebuild the revisions baseline: `uv run -m solaris.tools.revs baseline --dir projects/<slug>`.

## Validate

- [ ] `ai/plugins/reporting/assets/render.sh` renders an existing report and the PDF picks up the theme
      (accent color and body font match `reports/theme.css`).
- [ ] `ai/manifest.json` shows `reporting` at `0.2.0` and no `ai/report/` path remains in the project
      outside `ai/.memory/` history files (logs and the session-context summary keep their historical
      mentions - leave those as-is).

## Revert

1. `git mv ai/plugins/reporting ai/report`, restore the previous shared copies from git history, set the
   manifest entry back to `{"name": "report", "version": "0.1.1"}`, revert the stylesheet links, and
   re-run `uv run -m solaris.tools.revs baseline --dir projects/<slug>` (step 6 keyed the baseline under
   `ai/plugins/reporting/...`; without the re-run, classify reports every moved-back file as missing).
