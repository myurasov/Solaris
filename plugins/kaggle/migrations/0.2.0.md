## Pre-flight

- The project has this plugin copied at `<pack>/plugins/kaggle/` (`<pack>` is the project's ai-pack folder: default
  `aipack/`, `ai/` in older projects, any name). Linked plugins and ad-hoc tasks run the live source and need nothing
  here.
- Pause whatever calls the gateway on its own (watchers, dashboards, cron or scheduler jobs): its path changes.

## Migrate

1. Update the copy (`install-plugin` update): every `shared/` file of 0.2.0 into `<pack>/plugins/kaggle/`,
   including the new `tools/` folder (`kaggle.py`, `kaggle_lb.py`, `kaggle_share.py`) and the new skills
   (`kaggle-cli.skill.md`, `kaggle-leaderboard.skill.md`, `kaggle-sharing.skill.md`, `how-to-kaggle.skill.md`).
2. Delete the old `<pack>/plugins/kaggle/kaggle.py` (moved to `tools/kaggle.py`) and
   `<pack>/plugins/kaggle/kaggle.skill.md` (now `kaggle-cli.skill.md`; left in place it would load a second
   "kaggle" skill with stale paths). Fold any project-side edit to either into the plugin first (`import-plugin`).
3. Repoint every use of the old gateway path `<pack>/plugins/kaggle/kaggle.py` to
   `<pack>/plugins/kaggle/tools/kaggle.py`: the pack's instructions, worker briefs, scripts and tools (including
   paths joined from parts, such as `os.path.join(root, "<pack>", "plugins", "kaggle", "kaggle.py")`), kernel
   READMEs, and cron or scheduler entries. Ask the owner to update any permission allow rule that names the old
   path (for example `Bash(python3 <pack>/plugins/kaggle/kaggle.py:*)`).
4. Record `{"name": "kaggle", "version": "0.2.0"}` in `<pack>/manifest.json` and re-baseline the `revisions` entries
   for `<pack>/plugins/kaggle/` (`revs baseline` does this, whatever the pack folder is named).
5. Restart what was paused.

## Validate

- From the project root, `python3 <pack>/plugins/kaggle/tools/kaggle.py --version` prints the pinned version with no
  reinstall (same pins and same folder, so `.venv-kaggle` is reused as it is).
- Neither `kaggle.py` nor `kaggle.skill.md` sits directly under `<pack>/plugins/kaggle/`, and nothing in the project
  names `<pack>/plugins/kaggle/kaggle.py` any more.
- A `competitions leaderboard <slug> --show` read through the gateway notes "leaderboard read saved" on stderr.

## Revert

- Restore the two old files and the manifest entry `{"name": "kaggle", "version": "0.1.0"}` from the plugin's git
  history, point the calls back at `<pack>/plugins/kaggle/kaggle.py`, and remove the 0.2.0 files (`tools/` and the
  new skills). Saved leaderboard snapshots and the sharing state in `~/.solaris/kaggle/` are data: keep them.
