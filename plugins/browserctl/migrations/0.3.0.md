# browserctl 0.3.0 - The Slack Web Skill Leaves the Plugin <!-- omit in toc -->

- [Moved Paths](#moved-paths)
- [Pre-flight](#pre-flight)
- [Migrate](#migrate)
- [Validate](#validate)
- [Revert](#revert)

For packs updating from 0.2.x. The plugin no longer ships `slack-web.skill.md`; browserctl itself (the tool, its
skill and its rule) is unchanged.

## Moved Paths

`<pack>/plugins/browserctl/slack-web.skill.md` -> removed, with no replacement in the plugin.

## Pre-flight

- The project has this plugin copied at `<pack>/plugins/browserctl/` (`<pack>`: the project's ai-pack folder).
  Linked installs need nothing: the skill is gone from the live source.
- Grep the pack (instructions, rules, skills, notes) for `slack-web` to see whether the project still relies on it.

## Migrate

1. If the project still uses the skill, keep it as a project-local skill: move it to
   `<pack>/skills/slack-web.skill.md` and repoint any reference. Otherwise delete
   `<pack>/plugins/browserctl/slack-web.skill.md`.
2. Update the rest of the copy (`install-plugin` update).
3. Record `{"name": "browserctl", "version": "0.3.0"}` in `<pack>/manifest.json` and re-baseline the `revisions`
   entries (`revs baseline`), which drops the removed file.

## Validate

- `<pack>/plugins/browserctl/` holds no `slack-web.skill.md`, and nothing in the pack points there.

## Revert

- Restore `slack-web.skill.md` and the manifest entry from the plugin's git history.
